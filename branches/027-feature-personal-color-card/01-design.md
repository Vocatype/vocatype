# 027 feature/personal-color-card — 설계 문서

## 변경 사유

사용자 결정(2026-10-22): 사운드 시그니처를 **퍼스널 컬러를 넣은 원형**으로 바꾸고, 공유 이미지(저장 카드)를 "기본 테마 + 퍼스널 컬러 톤은 아우라와 원형 파형에만" 형태로 고정한다. 대화에서 만든 시안 A 2번째(가을 웜, 실제 WFQV 초상을 넣은 1080×1920 렌더)가 기준이다.

함께, 실제 공유 카드에서 원형 파형이 한쪽만 길게 튀어나온 덩어리처럼 보이는 문제를 고친다. 지금은 가장 큰 순간을 1로 맞추므로 한 번 크게 낸 소리(기침, 파열음)가 있으면 나머지 막대가 모두 짧아진다.

## 범위

### 1. 사운드 시그니처 (`src/features/signature/signature.ts`)

- `resampleEnvelope`: 180칸 평균 뒤 **상위 5%(95번째 백분위수)를 1로** 맞추고 그 위는 1로 자른 다음, 제곱근으로 작은 값을 끌어올린다. 튀는 한 순간이 전체를 누르지 않고 고르게 찬 고리가 된다
- `signatureColors(palette, count, background)`: 막대마다의 색. 팔레트의 앞 4색을 시간 순서(12시에서 시계 방향)로 지나 첫 색으로 돌아온다(고리의 이음매가 보이지 않게). 다섯째(가장 밝은 색: 크림·화이트 등)는 쓰지 않는다
  - `'dark'`(저장 카드, 어두운 화면): 흰색 쪽으로 18% 밝힌다
  - `'light'`(밝은 화면): 검은색 쪽으로 25% 어둡게 한다(여름 쿨·봄 웜의 옅은 색이 흰 바탕에서 사라지지 않게)

### 2. 결과 화면

- `SoundSignature`: 막대별 색 배열(`colors`)을 받을 수 있게 한다. 색 배열을 쓰면 안쪽 원 테두리는 그리지 않는다(시안과 같이)
- `ResultScreen`의 사운드 시그니처 카드: 퍼스널 컬러 팔레트와 현재 테마(`useTheme().resolved`)로 막대 색을 넘긴다
- 자리표시 초상(`PortraitFrame`) 위의 고리는 그라데이션 위에서 읽혀야 하므로 지금처럼 한 가지 잉크색을 유지한다(정규화 개선만 함께 적용)

### 3. 저장 카드 (`src/features/export/renderCard.ts`)

시안 A 2번째로 다시 그린다. 기본 테마는 모든 타입이 같고, 퍼스널 컬러 톤은 아우라·원형 파형·색 견본에만 들어간다.

| 순서 | 요소 | 시안 기준 |
| --- | --- | --- |
| 배경 | 어두운 바탕 `#141319` + **아우라**: 팔레트 1·2번째 색의 부드러운 원형 번짐 두 겹(초상 뒤) | 지금의 위아래 긴 번짐을 대체 |
| 상단 | 서비스 이름(왼쪽), 날짜(오른쪽) | 그대로 |
| 초상 | 둥근 정사각형, 얇은 흰 테두리(12%) | 크기만 조정 |
| 타입 | 코드(자간), 이름(최대 2줄), 해설 캡션(1줄, 없으면 생략) | **타입 설명 문단 제거** |
| 축 | 2×2 배치, "글자 라벨"과 흰색 얇은 막대(신호 부족이면 생략) | **퍼센트 제거**, 막대 색은 팔레트 대신 흰색 |
| 퍼스널 컬러 | 제목, 계절 이름, 오른쪽에 작은 원 5개 | **16진수 표기·큰 사각 견본 제거** |
| 향 | 제목, 향 이름(최대 2줄) | **탑·미들·베이스 노트 줄 제거** |
| 궁합 | "최고의 짝 / 정반대" 두 줄, 라벨 옆에 이름(1줄, 말줄임) | **섹션 제목·타입 코드 줄 제거** |
| 원형 파형 | 향·궁합 오른쪽에 퍼스널 컬러 톤 고리 | **라벨과 평균 음높이·음절 통계 제거** |
| 하단 | "『제목』 낭독 · Vocatype"(제목이 없으면 "Vocatype · 태그라인") | 두 줄 → 한 줄 |

- 구분선(섹션 제목 아래 가로줄) 제거
- `CardLabels`에서 쓰지 않게 된 값(`signature`, `match`, `top`, `middle`, `base`, `stats`)을 지운다. 화면의 사운드 시그니처 카드 통계 문구는 그대로 둔다(저장 카드에서만 빠짐)
- 세로 예산 규칙은 유지한다: 줄 수 제한이 모두 꽉 찬 최악 조합(영어 긴 이름 2줄, 캡션, 향 이름 2줄)도 `FOOTER_TOP − BUDGET_RESERVE(60)` 위에서 끝나야 하고, 넘치면 예외를 던진다(테스트로 단언)
- 영어 라벨("Polar opposite")이 한국어보다 길어도 궁합 이름이 라벨과 겹치지 않게, 이름의 시작 위치를 두 라벨 중 넓은 쪽 기준으로 정한다

### 제외

- 결과 화면의 다른 카드 배치(설명 문단·통계·노트는 화면에 그대로 있다)
- 초상 이미지 생성 방식
- 사운드 시그니처 문구의 "당신만의"(별도 작업)

## 결정과 근거

| 결정 | 근거 |
| --- | --- |
| 95번째 백분위수 + 제곱근 | 최댓값 정규화는 튀는 한 순간에 약하다. 백분위수는 그 순간을 1로 자르고, 제곱근은 쉼·약한 음절을 너무 지우지 않는다. 시안 렌더에서 고르게 찬 고리를 확인했다 |
| 팔레트 앞 4색 + 처음 색으로 복귀 | 다섯째는 계절마다 크림·화이트라 어두운/밝은 바탕 중 하나에서 사라진다. 처음 색으로 돌아와 고리 이음매가 끊겨 보이지 않는다 |
| 바탕에 따라 밝히기/어둡게 하기 | 같은 팔레트라도 어두운 카드에서는 밝혀야, 밝은 화면에서는 어둡게 해야 보인다 |
| 저장 카드 내용 줄이기 | 사용자 피드백 "난잡하다". 이미지는 공유용이라 한눈에 읽히는 것만 남기고 자세한 내용은 결과 화면에 둔다 |
