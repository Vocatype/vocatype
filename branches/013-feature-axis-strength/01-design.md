# 013 feature/axis-strength — 설계 문서

## 목표

16타입을 더 나누지 않고, MBTI처럼 **각 축이 어느 쪽으로 얼마나 기울었는지**를 결과 화면과 저장 이미지에 보여 준다.
경계(0.5 근처)에 있는 축은 "반대 성향도 조금 있어요"라고 알려 재녹음 때 타입이 바뀌어도 납득이 되게 한다.

## 범위

- `src/features/profile/axisStrength.ts`: 6축 값 → 타입을 정한 4축의 강도(`letter`, `label`, `otherLabel`, `percent` 50~100, `boundary`)
- `present.ts`: `axisLabels: string[]` → `axes: AxisStrengthView[]`(현재 언어로 풀린 값)
- `ResultScreen`: 칩 4개 → 축 행 4개(글자 + 라벨, 퍼센트, `role="meter"` 막대, 경계 안내)
- `renderCard`: 칩 → 한 줄에 작은 막대 4개(라벨·퍼센트·막대). 세로 예산 1800 안 유지
- 메시지 `result.axisBoundary`, 스타일, 테스트(강도 계산, 프레젠터, 카드 좌표·예산)

## 규칙

- 축 값 `v`(0..1): `v ≥ 0.5`면 왼쪽 글자(W/F/Q/V), 아니면 오른쪽. 퍼센트는 결정된 쪽으로 기운 정도 `max(v, 1−v) × 100`이라 항상 50~100.
- 경계형: 표시 퍼센트 `< 55`(즉 `|v − 0.5| < 0.045`, 반올림 때문에 표시값 기준으로 판정해 좌우가 대칭). 안내 문구는 반대쪽 라벨을 넣어 "{other} 성향도 조금 있어요".
- 축 순서는 타입 코드 글자 순서(온도·밀도·속도·흐름)와 같다.
