# 015 docs/portrait-seed-check — 설계 문서

## 배경

007에서 초상 모델을 Leonardo Lucid Origin으로 바꾸며 `seed` 결정성("같은 씨앗이면 같은 얼굴")을 확인하려 했으나, 무료 할당량 소진으로 미확인 상태로 남았다(README "Workers AI 켜기" 3번, 인수인계 후보 2번).
README는 `curl … | shasum`으로 두 응답의 해시를 비교하라고 안내한다.

## 목표

- 배포 Worker에 같은 `{typeCode, seed}`를 두 번 보내 결정성을 실측한다.
- 대조군으로 다른 씨앗을 한 번 보내, 씨앗이 실제로 결과를 바꾸는지(프롬프트만으로 같은 그림이 나오는 것이 아닌지) 확인한다.
- 결과를 README(확인 절차·알려진 한계)와 이 폴더 문서에 기록한다. "같은 얼굴이 아님"이면 모델 교체를 후속 작업으로 제안한다.

## 범위

### 포함

- `README.md` "Workers AI 켜기" 3번 절차와 "알려진 한계" 수정
- `worker/ai/workersAi.ts` 모델 상수 주석 한 줄(결정성의 범위)

### 제외

- 코드 동작 변경, 모델 교체, 테스트 변경

## 방법

- 호출: `POST https://vocatype.hs827.workers.dev/api/portrait`, 본문 `{"typeCode":"WFQV","seed":123}` 2회(수 초 간격), 대조군 `{"typeCode":"WFQV","seed":456}` 1회.
  총 3회 ≈ 4,500뉴런으로, 하루 무료 할당량(10,000뉴런, 초상·리딩 공용)의 절반 이하로 제한한다. 운영 사이트가 같은 할당량을 쓰므로 더 돌리지 않는다.
- 판정 세 가지를 모두 기록한다.
  1. 응답 바이트·SHA-256 비교(README의 기존 안내).
  2. JPEG를 디코딩해 픽셀 차이: 채널 평균 절대차(0~255), 완전히 같은 픽셀 비율, 채널 최대차가 8·32를 넘는 픽셀 비율.
  3. 눈으로 얼굴·구도·조명 비교.
- 해석 규칙: 해시가 달라도 같은 씨앗 쌍의 픽셀 차이가 작고(다른 씨앗 쌍과 뚜렷이 구분되고) 같은 얼굴이면 "결정적"으로 본다. GPU 부동소수점 비결정성으로 바이트가 조금씩 달라지는 것은 확산 모델에서 흔하다. 같은 씨앗 쌍의 차이가 다른 씨앗 쌍과 구분되지 않으면 "비결정적"으로 보고 모델 교체를 제안한다.
