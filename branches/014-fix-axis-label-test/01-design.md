# 014 fix/axis-label-test — 설계 문서

## 배경

013 2차 리뷰 반영 때 긴 라벨 테스트의 폭 상한을 `barWidth − 폭('100%') − 12`로 조였는데, 구현은 **그 축의 실제 퍼센트 문자열** 폭만 남기므로 퍼센트가 100%가 아닌 축에서 0.16px 차이로 실패했다.
검사 출력에 `grep`을 걸어 종료 코드가 가려진 탓에 실패를 못 보고 병합·푸시했다.

## 목표

- 테스트 기준을 구현과 같게: 축마다 `barWidth − 폭(그 축의 퍼센트) − 12`(부동소수점 여유 0.01).
- 재발 방지: 검사 체인에서 `npm test`의 종료 코드를 직접 확인한다(출력 필터와 분리).

typecheck / lint / test / build 통과(종료 코드 확인).
